# pocketRulebooks

보드게임 룰을 적어 두고, 필요할 때 꺼내 보는 안드로이드 앱입니다.

## APK 설치

1. [Releases](https://github.com/joongsoo89/pocketRulebooks/releases)에서 `pocketRulebooks.apk`를 받거나, 이 저장소의 [`releases/pocketRulebooks.apk`](releases/pocketRulebooks.apk)를 받습니다.
2. 안드로이드 폰에서 파일을 열고 설치합니다.
3. 처음이면 **알 수 없는 앱 설치**를 허용해야 할 수 있습니다.

## 앱 기능

- 보드게임 목록에서 골라 룰 확인
- 룰 5개 탭: 개요(목표), 준비, 진행, 종료(점수계산), 기타
- 게임 추가, 편집, 삭제
- 게임마다 룰북을 `.txt`로 가져오기/내보내기
- 화면 언어: 한국어 / 日本語 / English
